# YieldProof

**We don't rate promises. We rate what actually pays.**

YieldProof is an evidence-backed testing, ranking, research, and decision-support platform for high-yield and passive-return platforms.

## Core principles

- Evidence first.
- Minimum practical exposure first.
- Recover external capital before optimising profit.
- A platform balance is still exposure until money reaches an external wallet.
- Reliability, capital recovery, and opportunity are scored separately.
- Affiliate economics never influence ranking or trust scores.
- SEO and public content are driven by real data and documented evidence.
- Secrets belong only in server-side secret stores / environment variables.

## Project systems

- Google Drive: operational evidence and working documents.
- Structured database: platform facts, tests, deposits, withdrawals, scores, SEO entities, and histories.
- Object storage: approved public evidence/media.
- This repository: code, schemas, research tooling, maths, scoring logic, tests, and deployment configuration.

The canonical project memory currently lives in the YieldProof Drive workspace under `00 - Blueprint & Strategy`.
